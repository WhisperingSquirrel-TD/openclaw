# SKILL: Morning Briefing

## When to use
Daily at 07:00, or when Tom asks for a briefing.

## Do NOT include
- ⚙️ SYSTEM HEALTH unless SYSTEM_HEALTH.md is non-empty and has active alerts
- Garmin data if GARMIN_DAILY.md is missing or stale (> 25 hours)
- Empty sections — omit any section with nothing to report

## Sections (include only if non-empty)

### 1. 🔔 Revenue / Leads
From STACKSTONE_ENQUIRIES.md — any new or unresponded enquiries since yesterday.
Flag revenue-critical items first.

### 2. 📅 Calendar
Today's confirmed meetings and calls. Flag any conflicts or prep needed.

### 3. 📋 Tasks
Top 3 from TASKS.md that need attention today.

### 4. 💪 Health (if available)
From GARMIN_DAILY.md:
- Resting HR, HRV status, sleep duration and score
- Body battery, stress level
- One sentence interpretation if anything is notable

### 5. 📬 Inbox
Summary from email and WhatsApp monitoring if anything notable overnight.

### 6. ⚙️ System Health (only if alerts exist)
From SYSTEM_HEALTH.md — only include if non-empty.

## Format
Keep it short. Bullet points. No preamble. No filler.
Total should be readable in 60 seconds.

## After briefing
Offer to build today's plan (runs daily-plan skill).
