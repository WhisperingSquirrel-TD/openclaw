# SKILL: Daily Plan — Build Today's Plan

## When to use
- Morning, during or after briefing
- When Tom asks "plan my day" or "what should I focus on today"
- When the calendar or priorities have shifted

## Inputs to gather (in order)
1. **Calendar** — what meetings/calls are confirmed today
2. **TASKS.md** — what active tasks need attention
3. **BACKLOG.md** — anything high-priority to work on
4. **GARMIN_DAILY.md** — energy/health context (if available)
5. **HEARTBEAT.md** — open loops from yesterday
6. **STACKSTONE_ENQUIRIES.md** — any unresponded leads

## Process

### Step 1 — Check calendar
Read today's calendar events. Note times, conflicts, prep needed.

### Step 2 — Review priorities
Cross-reference TASKS.md and BACKLOG.md against the day's schedule.
Apply Tom's priority order: Revenue → Time-sensitive → Operational → Background.

### Step 3 — Health context
If GARMIN_DAILY.md is recent, factor in energy level. High stress or poor sleep = protect deep work time.

### Step 4 — Build the plan
Write a clear, time-aware plan to PLAN.md:
- Focus: one primary goal
- Schedule: key meetings with prep notes
- Tasks: 3-5 specific action items in priority order
- Notes: anything else worth keeping top of mind today

### Step 5 — Confirm
Post the plan summary to Telegram. Offer to adjust.

## Output format (PLAN.md)
```
# PLAN.md — [Day, Date]

## Focus
[primary goal]

## Schedule
- HH:MM — [event] [prep note if needed]

## Tasks
- [ ] [task] — [context]

## Notes
[anything else]
```
