# App Plan

Use this skill at the start of any new app request.

## Goal

Turn a rough app idea into a clear build plan before any implementation starts.

## Process

1. Clarify the goal, users, core workflow, and non-goals.
2. Define the smallest useful version first.
3. Identify what must be proven in build vs what can wait.
4. Produce a concise implementation plan with clear phases.
5. Route actual implementation to the app workflow (`app-init`/template use, `app-build`, `app-test`, `app-deploy`) rather than building from vague intent.

## Notes

- Do not start coding from an unclear idea.
- Prefer a smaller first version with explicit acceptance criteria.
- Keep the plan lightweight and practical.
