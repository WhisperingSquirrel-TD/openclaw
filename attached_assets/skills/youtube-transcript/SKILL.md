# YouTube Transcript Skill

Extract transcripts (captions/subtitles) from YouTube videos. No API key needed.

---

## When to use

- User shares a YouTube link and asks you to summarise, analyse, or reference the video content
- User asks "what does this video say?" or "get the transcript of this video"
- You need to ingest video content for research or context

## Script location

```
~/.openclaw/integrations/youtube/transcript.py
```

---

## Usage

### Basic transcript (plain text, no timestamps)

```bash
python3 ~/.openclaw/integrations/youtube/transcript.py "https://www.youtube.com/watch?v=VIDEO_ID"
```

### With timestamps

```bash
python3 ~/.openclaw/integrations/youtube/transcript.py "VIDEO_ID" --timestamps
```

Output format with timestamps:
```
[00:00] Introduction text here
[01:23] Next segment of speech
[05:47] Another segment
```

### Different language

```bash
python3 ~/.openclaw/integrations/youtube/transcript.py "VIDEO_ID" --lang es
```

Falls back to auto-generated captions if manual captions aren't available in the requested language. If the requested language isn't available at all, falls back to whatever language IS available.

### List available languages

```bash
python3 ~/.openclaw/integrations/youtube/transcript.py "VIDEO_ID" --list-langs
```

### Raw JSON output (for programmatic use)

```bash
python3 ~/.openclaw/integrations/youtube/transcript.py "VIDEO_ID" --raw-json
```

Returns JSON with `video_id`, `source`, `segments` count, and full `transcript` array with `start`, `duration`, and `text` fields per segment.

---

## Accepted URL formats

All of these work:
- `https://www.youtube.com/watch?v=dQw4w9WgXcQ`
- `https://youtu.be/dQw4w9WgXcQ`
- `https://youtube.com/shorts/dQw4w9WgXcQ`
- `https://youtube.com/embed/dQw4w9WgXcQ`
- `dQw4w9WgXcQ` (bare video ID)

---

## Exit codes

| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | No transcript available (video has no captions at all) |
| 2 | Video not found, private, or invalid URL |
| 3 | youtube-transcript-api library not installed |

---

## Limitations

- Only works for videos that have captions (manual or auto-generated by YouTube)
- Videos with no captions at all will return exit code 1 — there is no workaround on the Pi
- Age-restricted or private videos may not be accessible
- Auto-generated captions can have accuracy issues, especially for technical content
- Very long videos (3+ hours) may take a few seconds to fetch

## What to tell the user

If a video has no captions:
> "This video doesn't have any captions available (manual or auto-generated), so I can't extract a transcript from it."
