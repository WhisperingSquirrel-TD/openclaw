# YouTube Transcript Skill

Extract transcripts (captions/subtitles) from YouTube videos. No exec required. No gate needed.

---

## When to use

- User shares a YouTube link and asks you to summarise, analyse, or reference the video content
- User asks "what does this video say?" or "get the transcript of this video"
- You need to ingest video content for research or context

---

## How to use

The `youtube_transcript` tool is built into your toolset. Call it directly — no exec, no gate, no Python script.

```
youtube_transcript(url="https://www.youtube.com/watch?v=VIDEO_ID")
```

The tool handles everything automatically:
- **Videos with captions** — fetches the native caption track instantly (free, no API key)
- **Videos without captions** — falls back to Gemini AI transcription (requires `GEMINI_API_KEY`, may take a few minutes for long videos)

---

## Parameters

| Parameter | Required | Description |
|-----------|----------|-------------|
| `url` | Yes | YouTube URL or bare 11-char video ID |
| `lang` | No | ISO language code e.g. `en`, `es`, `fr` (captions path only) |
| `includeTimestamps` | No | `true` = prefix each line `[MM:SS] text` (captions path only) |

---

## Accepted URL formats

All of these work:
- `https://www.youtube.com/watch?v=dQw4w9WgXcQ`
- `https://youtu.be/dQw4w9WgXcQ`
- `https://youtube.com/shorts/dQw4w9WgXcQ`
- `https://youtube.com/embed/dQw4w9WgXcQ`
- `dQw4w9WgXcQ` (bare 11-character video ID)

---

## Response fields

| Field | Meaning |
|-------|---------|
| `transcript` | Full transcript text |
| `source` | `"captions"` = native YouTube captions; `"gemini_ai"` = AI-generated |
| `lang` | Detected language (captions path) |
| `model` | Gemini model used (AI path only) |
| `note` | Present on AI path — reminds that AI transcripts may not be 100% verbatim |
| `segmentCount` | Number of caption segments (captions path only) |
| `cached` | Whether result came from 24h cache |
| `truncated` | `true` if transcript exceeded 80,000 characters |
| `error` | Human-readable error if both paths failed |

---

## Error meanings

| Error | Meaning |
|-------|---------|
| "YouTube is rate-limiting this server's IP" | Wait a minute and retry |
| "Video unavailable or private" | Video deleted, private, or bad URL |
| "No transcripts are available in [lang]" | Requested language unavailable — error lists what is |
| "GEMINI_API_KEY … required" | No captions AND no Gemini key — tell user to configure key |
| "AI transcription failed" | Gemini call failed — check detail in error field |

---

## What to tell the user

If a video has no captions and no Gemini key is configured:
> "This video has no captions. I can transcribe it using AI (Gemini), but that needs a Gemini API key to be set up first."

If AI transcription is used:
> "No captions were available for this video, so this transcript was generated by AI — it should be accurate but may not be word-perfect."
