## Interpretation rules

- A declared manual/event trigger is usable as a **proposal for invocation** only when a current owner request or proven event supplies it.
- A declared cron/daily/heartbeat trigger is **not** a scheduler record. Proving it requires the scheduler configuration, a run record, and (where relevant) a destination delivery receipt.
- A source reference to a skill is **not** runtime wiring. Proving wiring requires the active gateway/worker path and an observable invocation.
- Live state is blocked for this review. Do not convert “configured-looking”, “textually referenced”, “tested”, or “present in the snapshot” into “active”.
